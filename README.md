# 🫠 MINGIZEOK.ZOOMOON
"어서오세요☺️ 주문 도와드리겠습니다!"  
세상에는 맛있는 음식이 정말 많다!!  
무얼 먹을지 정하지 못한 당신을 위해 준비했다..!!

[⁉️ ZooMoon, 메뉴를 정하지 못한 당신을 위해.](https://zoomoon.mingizeok.com)

### 프로젝트 배경 & 목표
- 매번 정하기 어려운 메뉴. 언제 어디서든 쉽게 메뉴를 선택할 수 있는데 목표한다.

## 핵심기능
- 기능 1: MENU, 메뉴 조회 및 추가 기능
- 기능 2: RADOM, 랜덤메뉴 추천 기능

## 기술 스택
- Python / Django
- DB : PostgreSQL
- Environment : venv, GitHub
- Front : Django Template 활용

## 페이지 소개
### MAIN
주문 ZOOMOON 첫 페이지

### TOTAL MENU
이 세상에는 맛있는 것들이 넘처나고 있다.  
✨ 전체 메뉴 조회 List  
: 메뉴들을 한 화면에 모아볼 수 있는 페이지.  

- 검색 기능 및 카테고리별 조회 기능 추가 예정

### ADD MENU
"아니.. 이 메뉴가 없다고..?"  
이 세상은 넓고 크다!  
✨ 메뉴 추가 페이지  
: 아직 없는 메뉴들을 추가할 수 있는 페이지.  

### RANDOM
메뉴를 고르지 못한 당신을 위한 기능..!  
✨ 랜덤메뉴 추천 페이지  
: 저장된 메뉴들 중에서 랜덤으로 추천합니다.
